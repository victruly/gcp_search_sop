Google 官方現成 搜尋小工具

此頁面使用 Google 官方提供的 <gen-search-widget>，由 Python 後端動態產生短期 OAuth 權杖（authToken）進行驗證。

OAuth 授權權杖（Auth Token）狀態
TOKEN ACTIVE
Config ID {{ config_id }}
產生來源 後端 Python API /api/token（使用服務帳戶金鑰自動簽發）
權杖前綴 載入中...
賦值程式碼 searchWidget.authToken = "<OAuth Access Token>";

使用 Google 官方小工具的注意事項

  • 允許網域 (Authorized Domains)：如果在點擊輸入框後小工具未彈出，請至 GCP 後台（應用程式 > PbSearch > 整合 > 小工具），檢查下方「授權網域」是否有加入 localhost。
  • 安全性優勢：此方式不需要將任何私密金鑰暴露給前端，前端僅持有由後端產生的短期（1 小時）OAuth 臨時權杖。
